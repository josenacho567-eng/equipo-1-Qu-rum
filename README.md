# Recetario del Equipo 🍲

¡Bienvenido al repositorio del **Recetario Colaborativo**! 

Este proyecto es una práctica de control de versiones diseñada para ejercitar el trabajo en equipo con Git. Combina trabajo en archivos independientes (para evitar conflictos) y edición en archivos compartidos (para aprender a resolver conflictos de fusión).

---

## 📋 Estructura del Repositorio

El proyecto está organizado de la siguiente manera:

| Archivo / Carpeta | Descripción | ¿Quién lo edita? |
| :--- | :--- | :--- |
| `README.md` | Descripción general y guía del recetario. | El líder del equipo |
| `EQUIPO.md` | Lista oficial de integrantes del equipo. | Todos |
| `recetas/<nombre>-<receta>.txt` | Archivo individual por cada receta (ej. `recetas/ana-arroz-con-pollo.txt`). | Solo su autor |
| `INDICE.md` | Lista completa e índice de todas las recetas compartidas. | Todos (archivo compartido) |
